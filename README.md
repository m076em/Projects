## CIV4100 - Building and Training a CNN to perform classification of traffic signs
- Augment a dataset of traffic sign images, using standard augmentation techniques such as Gaussian noise, salt and pepper noise, rotation, zoom, and shear.
- Split augmented dataset into training, testing, and validation sets.
- Decide the structure of the CNN model, that is, the number of layers, activation functions at each layer, and the width of each layer.
- Build, train and validate the CNN using the tensorflow Python library on the augmneted dataset.
- Test the trained CNN on the testing dataset.
- Upload the CNN weights to Kaggle to be deployed and tested on a kaggle dataset
